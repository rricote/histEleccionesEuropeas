# Elecciones al Parlamento Europeo en España (1987-2024)

Resultados por España, comunidad autónoma, provincia, municipio y sección censal, a partir de los ficheros por mesa del Ministerio del Interior.

- `index.html`: España (escaños, hemiciclo del Parlamento Europeo por grupos, mapa, análisis y partidos).
- `ccaa.html?c=01`, `provincia.html?p=28`, `municipio.html?m=28079`; el parámetro `e=2019-05` elige la elección.
- `datos/`: resultados por elección. `mapas/`: mapas de comunidades, provincias, municipios y secciones censales (INE).
- `fuentes/`: scripts con los que se generaron los datos y mapas.

Para publicarlo con GitHub Pages: Settings → Pages → rama `main`, carpeta raíz. También funciona abriendo `index.html` con doble clic.
